# 제품 요구사항

## 목표

대한민국 공공기관 및 교육기관에서 일용직과 단기계약직의 근무 기록부터 급여 산정, 외부 결재, 지급 및 보고까지 관리합니다.

## Phase 1 범위

- 최초 시스템 관리자 등록, 로그인과 로그아웃, 역할 및 활성 상태 검사
- 한국어 대시보드, 공통 사이드바, 헤더
- 사용자·부서·예산과목 목록, 검색, 필터, 정렬, 등록 및 수정, 활성 상태 관리
- 부서 관리자 소속 부서 범위 검사
- 관리자 설정 변경 및 로그인 성공 감사 기록
- 그룹웨어 및 은행 파일 인터페이스와 테스트 가능한 기본 구현

## 이후 단계

지급 배치에서 일별·주별·월별·수시 주기를 지원합니다. 근무는 직접 입력과 Excel 업로드를 지원하며 같은 검증 모듈을 사용합니다. 승인 상태는 외부 그룹웨어를 기준으로 관리합니다. 은행 규격 확인 후 어댑터를 단계별로 추가합니다. 검토받은 급여 정책 버전이 유효한 기간에만 실제 지급으로 진행합니다. 예산과목 건수와 고유 근로자 수를 별개로 집계합니다.
