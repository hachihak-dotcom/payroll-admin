# 개발 계획

| 단계 | 범위 | 검증 |
| --- | --- | --- |
| 1 | 로그인, 역할, 대시보드 및 기준정보 | 실제 PostgreSQL 및 브라우저 E2E |
| 2 | 근로자·계약·계좌·예산과목 연결 | 중복, 기간, 암호화, 이력 검증 |
| 3 | 근무내역 직접 입력과 Excel | 시간 검증, 중복, 업로드 미리보기와 반영 |
| 4 | 계산 엔진, 지급 배치, 정책 및 예산 배분 | 금액 검산, 정책 승인, 이중 정산 방지 |
| 5 | 외부 전자결재 | 중복 방지, 외부 상태, 실패·재시도 |
| 6 | 은행 파일과 지급 결과 | 금액 검산, 결과 구분, 이력 |
| 7 | 보고서와 운영 준비 | 엑셀, 집계, 권한·보안·통합 검증 |

## Phase 2 상세 범위

1. 고유 근로자 번호, 일용직·단기계약직 구분, 소속 부서와 활성 상태를 기록하는 마이그레이션을 추가합니다.
2. 연락처와 계좌 등 근로자 민감정보에 버전이 포함된 애플리케이션 암호화를 적용하고 조회 응답을 마스킹합니다. 키를 서버 환경에서 관리하고 회전 방법을 정의합니다.
3. 소속 부서 관리자, 급여 담당자, 조회 사용자 각각의 열람 및 편집 범위를 서버 정책으로 적용합니다.
4. 계약 기간, 시급·일급·월급, 일별·주별·월별·수시 지급 주기, 기본 예산과목을 검증합니다.
5. 종료·재계약과 계약 변경 이력을 기록하고 미래 급여 결과가 계약 버전에 연결되도록 식별자를 유지합니다.
6. 근로자·계좌·계약 관리 폼과 목록을 연결하고, 중복 등록, 기간 역전, 마스킹, 권한, 변경 이력의 단위·통합·E2E 테스트를 추가합니다.
