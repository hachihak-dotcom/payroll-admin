# 급여 정책

급여 산정은 Phase 4에 구현합니다. 외부 노무·세무 검토로 확인된 정책의 버전, 유효 시작일과 종료일, 검토 상태를 저장하며 기간과 상태가 충족돼야 실제 지급으로 진행할 수 있습니다.

계약 단가, 기본급, 연장·야간·휴일·기타 수당 및 세금·보험·기타 공제를 항목별로 산출합니다. 구현 시 정수 원화와 명시적 반올림 규칙을 사용하고, 계약·근무시간·정책과 계산 결과를 함께 고정합니다. 승인된 세율·보험요율·수당 조건·반올림 규칙의 확보가 선행되어야 합니다.

예산과목 집계는 총지급액, 공제액, 실지급액, 지급 건수, 근로자 고유 인원, 평균, 중앙값을 계산합니다. 예산과목별 고유 인원과 전체 고유 인원은 각각 집계합니다.
