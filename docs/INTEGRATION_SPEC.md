# 외부 연계

## 전자결재

`GroupwareApprovalProvider`는 고유 요청 키를 사용해 지급 배치 결재를 요청하고, 문서 ID로 진행 상태를 조회합니다. 모의 구현은 요청 키 재사용, 대기에서 승인·반려·취소로의 전환, 반려 사유를 테스트할 수 있습니다. 모의 상태는 프로세스 메모리에 보관하고 프로덕션에서 초기화를 차단합니다.

Phase 5에서 실제 그룹웨어의 인증, API, 상태 매핑, 재시도 및 중복 이벤트 키를 반영합니다. 외부 문서 ID와 이벤트를 영속화합니다.

## 은행 파일

`BankFileAdapter`의 초기 어댑터는 UTF-8 범용 CSV를 생성합니다. 대상의 참조 번호 중복, 계좌 및 은행 코드의 기본 형식, 양수 원화 금액을 검증합니다. 금액 합계는 정수로 계산합니다. CSV 작성 시 수식 문자와 선행 0을 처리합니다. 현재 어댑터는 다운로드 API나 지급 상태를 변경하는 기능 없이 단위 테스트에서 검증합니다.

Phase 6에서 은행별 규격을 확보하면 전용 형식을 추가합니다. 생성 및 다운로드 이력과 지급 완료·실패 상태는 별도로 기록합니다.
