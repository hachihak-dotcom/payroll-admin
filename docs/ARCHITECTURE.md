# 아키텍처

Next.js App Router의 Server Components는 Auth.js 세션과 PostgreSQL의 최신 계정 상태로 접근을 판정합니다. Server Actions가 로그인·로그아웃·최초 설정을 처리합니다. 관리 화면은 공통 REST 쓰기 경로를 호출하고 동일한 Zod 검증을 서버에서 다시 적용합니다. Prisma가 전용 PostgreSQL 스키마를 사용합니다.

| 역할 | Phase 1 접근 |
| --- | --- |
| SYSTEM_ADMIN | 사용자, 부서, 예산과목 조회와 변경 |
| PAYROLL_MANAGER | 부서와 예산과목 조회 |
| DEPARTMENT_MANAGER | 소속 부서와 예산과목 조회 |
| VIEWER | 부서와 예산과목 조회 |

사용자의 부서, 역할, 이메일, 비밀번호, 활성 상태 변경 시 기존 JWT를 무효화합니다. 부서 관리자 계정에는 활성 부서가 필요합니다. 시스템 관리자 역할은 외부 결재 권한을 부여하지 않습니다.

비밀번호는 임의 솔트와 scrypt로 해시합니다. 로그인은 15분 단위 IP와 계정 제한을 적용합니다. Vercel은 플랫폼이 제공한 IP 헤더를 사용하고 로컬이나 별도 프록시 배포는 공유 한도를 적용합니다. 인증 시도 테이블에는 이메일·IP 원문 대신 HMAC 키를 보관합니다. 운영에서는 오래된 시도 행을 정리할 별도 유지보수 작업을 두는 것이 적절합니다.

관리 REST 쓰기 요청은 같은 출처의 JSON만 허용합니다. 페이지는 매 요청마다 사용자 상태를 다시 확인합니다. 역할 변경, 부서 비활성화, 최초 관리자 등록은 PostgreSQL 트랜잭션 잠금으로 직렬화합니다. 관리 변경과 감사 로그는 같은 트랜잭션에 저장합니다.
